INTERACTIVE ROUTING

Connect two pieces

Use Select trace or the list to choose a route. In Select trace mode, Delete or Backspace removes the selected trace. Edit selected route lets you drag bends or the middle of a trace; release to preview and Enter to confirm. Artwork restores wherever the revised routes no longer need trimming. Removing it restores artwork from the remaining routes. Undo restores the removed route.

Choose Route, then click the first and second assigned pieces. A shared mesh net sets the layer.

Manual mode: choose endpoints, then click waypoints in order. Check path highlights blocked sections in red and switches to point editing. Drag points, then check again. Double-click a line to add a point. Enter checks and saves a valid path.

Choose two assigned pieces to begin.

After choosing endpoints, click inside each passage you want the path to follow, in order. Enable live cursor preview to see a waypoint before clicking. Amber artwork and traces show proposed push changes; dashed lines show the old trace positions. Delete or Backspace removes the last waypoint. Enter confirms a ready preview. Escape cancels.
