Setup and supported edits

Frozen segment nets

Ignores all old net names on both layers. Restores connector names and follows touching islands and traces. Floating groups get FLOAT names; groups touching several connectors get CONFLICT names. Undo restores previous assignments.

Fine tune slice

Drag the orange endpoints. Hold Alt for free movement. Escape cancels dragging. Changes preserve island count and net assignments; Undo restores the previous slice.

Physical dimensions

Manufacturing limits: trace width ≥ 0.12 mm; same-layer trace spacing ≥ 0.12 mm; segment-to-trace spacing ≥ 0.12 mm. Top/bottom traces need ≥ 0.10 mm projected spacing outside segment and wanted-overlap areas, inside the display.

Artwork and trace centerlines scale with the screen. Trace widths, pad sizes and clearance stay in millimetres. Recheck after resizing.

Export conductors

DXF layers

One file with selected AutoCAD layers. Millimetres, 1:1, registered front view; bottom is not mirrored. TOP/BOTTOM include electrodes, traces and pads. SEGMENT includes current slices, moves and vertex edits. Closed outlines and solid fills preserve holes.

Both layers use registered front-view coordinates. Exports contain assigned conductors only; they are not factory-approved masks.

How to route
  1. Select a segment and assign its top and bottom net names.
  2. Choose a layer, routing net and trace width.
  3. Draw from an island toward a pad. Click bends; double-click or Enter to finish. Endpoints snap to pads and trace vertices.
  4. Touched islands take the trace’s net unless another net’s trace touches them. A floating net routed to an edge pad adopts that pad’s net. Top is red; bottom is blue.
  5. Use Erase to remove a whole trace, or select one and press Delete. Undo restores it.
  6. Run checks. Fix missing islands, duplicate pairs between different original groups, shorts and overlaps outside the original shapes.
  7. Save JSON to keep an editable project. Local autosave also preserves the latest layout in this browser.

Space-drag or middle-drag pans; wheel zooms. V selects, R draws, E erases, H pans. Ctrl/Cmd Z undoes; Shift Z or Ctrl Y redoes. Ctrl/Cmd S saves; O loads. Loading and New are undoable.
