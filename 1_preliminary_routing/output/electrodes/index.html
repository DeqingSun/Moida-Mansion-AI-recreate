What this design does—and what remains unresolved

This is a static-drive reference candidate: 631 independent front SEG signals against one rear COM signal. Every original visible island is retained. Some front electrodes have routed traces and perimeter contacts; the others are isolated conductor shapes. Rear cutouts remove overlap beneath connecting traces. Separate contacts for islands of one logical segment must be tied together on the external PCB.

The exact polygon checks reproduce all 631 source shapes, but the current automatic routing does not reach every island. The simulator exposes that difference. Do not manufacture these masks. A practical redesign must solve the blocked routes, rear continuity, narrow necks, contact fanout, driver loading and supplier design rules; the chosen high-contact-count static architecture has not been proven viable.

How the electrical simulation works

Static AC drive alternates between two half-cycles. A front electrode in phase with COM sees 0 V across the liquid crystal; an electrode in opposite phase sees +V then −V, with RMS equal to V. The waveform panel is a slowed schematic of a nominal 60 Hz drive, not a display refresh animation. The chosen threshold is illustrative, not a measured liquid-crystal response.

“Direct electrode probes” assumes an ideal probe touches every island and every rear fragment. This tests the overlap geometry for all 631 groups and deliberately bypasses wiring. “Routed edge contacts” only lights an island if a verified front route and a connected rear electrode reach it. Floating islands are omitted, not physically modeled; parasitic ghosting could occur on real glass.

Voltage/threshold controls use a binary RMS model. ITO resistance, capacitance, settling, fringing, optical contrast and manufacturing tolerances are not simulated.

Validation and the meaning of “all combinations”

There are 2^631 possible segment images, so exhaustive frame enumeration is not practical. The geometric audit checks every island's front/back intersection against the original filled shape, including unwanted trace overlap. The browser sweeps all 631 one-hot states and all 631 one-cold states, and also checks all-off, all-on and deterministic random frames. This verifies the independent ideal model; it does not turn an incomplete physical route into a connected electrode.
